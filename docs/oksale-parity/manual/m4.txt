전표작성
수금지급, 기간별 세금계산서 외 매입, 매출, 반입, 반출, 견적서, 발주서 등의
모든 업무가 처리되는 메뉴입니다. 기본 사용법은 모두 같으므로 하나의 전표
사용법만 알며 모두 사용할 수 있습니다.


전표작성 창의 이해
매입, 매출, 반입, 반출, 견적서, 발주서 등을 실제 작업이 하게됩니다.




전표일자: 기본적으로 오늘의 날짜가 나오면 날짜 변경은 상하 방향키를 사용
하거나 날짜 입력창 오른쪽 역삼각형을 클릭하여 달력창이 나오면 달력창에서
선택할 수 도 있다.
전표구분: 1매출, 2매입, 3반입, 4반출, 5견적, 6발주, 7납품 등으로 구성된다.
부가가치세: 세액의 포함 여부를 선택하는 곳으로 한 번 선택되면 계속 유지
되므로 주의 하여야 한다.
전잔액 출력: 거래명세표 발행시 전잔액출력 체크박스가 체크되어 있으면 이
전 미수금이 출력된다.
단가소수점: 환경설정에서 설정한 소수점 자리수가 기본으로 설정되나 전표작
업중 바꾸고자 할 때 클리하면 단가 소수점 자리수가 0, 1, 2 로 계속 바뀐다.
거래처명: 전표 작업을 할 상대 거래처명을 등록한는 입력박스다. 두 자 정도
입력하고 [Enter]키를 누르면 거래처 리스트 창이 나온다. 이 때 작업할 거래
처가 있으면 [Enter]키로 선택하고 없으면 바로 등록하거나 수정하여 선택한
다.
현장명: 거래처명 입력시 선택된 현장의 현장명, 담당자, 전화번호 등이 표시
된다.
품목수, 총액, 합계, 세액, 전잔액: 전표 작업시 작업중인 자료의 품목수, 총
액(공급가액), 세액, 전잔액을 표시한다.
상품 입력 리스트: 전표작업에 필요한 상품, 수량, 단가 등을 입력하게 된다.
최근매입가, 판매단가, 협정가, 이익률, 최근거래일, 단가변동일, 현재고: 머
니플러스 만의 장점중 하나로 전표 작업을 하는 순간 필요한 정보를 바로 확
인할 수 있다.

                             면 잘 못된 전표는 삭제할 수 있다.

전표작성창, 전표리스트 창의 변환은 [F2]키를
사용하거나 전표리스트, 전표작성 메뉴를 클릭
하면 된다.

                             l 매출이면 1, 매입이면 2 등 작업할 내용에 따라 해당 번호를 치고 [Enter]키를 누른

l 거래처명 입력박스에 해당 거래처명을 두자정도 입력하고 [Enter]키를 누른다.




l 등록된 거래처명 있으면 검색창 리스트에 해당 거래처를 [Enter]키를 눌러 선택하고
  리스트에 없으면 [Insert]키를 눌러 거래처 등록을 해준다.
l 새로운 거래처 등록을 마치면 [Esc]키를 눌러 검색창 리스트로 돌아간다. 이 때 최근
  에 등록된 거래처가 바로 리스트화면에 뜨고 다른 거래처명으로 다시 검색하고자하
  면 [F2]키를 눌러 찾으면 된다.




l 전표 입력리스트 품명 셀에서 상품명을 두자정도 입력하고 [Enter]키를 누른다.

                              할인율 입력난에 적용할 할인율을 입력후 [Enter]키를 누른다.

새로운 견적서 작성
전표구분에서 5번 견적을 선택하고 나머지 사용법은 전표작업과 같으며 전표
입력창 하단의 명령버튼만 바뀌게 된다.




l 모든 상품이 등록되면 창 하단의 견적서 명령버튼을 클릭한다. 참조사항을 입력할 수
  있는 창이 나타나고 이 때 필요한 내용을 입력 후 [Enter]키를 누른다.




l 잠시 후 Windows 창 하단에 아래와 같이 파란 창메뉴가 새로 만들어 진다. 이 메뉴를
  클릭하면 미리보기 창을 볼 수 있게 된다.
l 미리 보기 창에서 내용을 확인 후 프린터 모양의 버튼을 누르면 바로 인쇄가 되며 편
  지봉투 모양의 버튼을 클릭하면 엑셀 파일 등으로 보낼수 있다.
전표수정
이미 작성된 전표내용을 수정하려면 전표리스트에서 해당 전표를 찾아 더블
클릭하거나 전표복사 명령버튼을 클릭하면 전표작성창으로 복사하여 수정할
내용만 수정후 새로운 전표작업과 같은 방법으로 작업하면 된다.




전표삭제
잘 못 처리된 전표를 삭제하려면 전표리스트에서 해당 전표를 찾아 삭제 명령
버튼을 클릭한다.




전표복사
이미 제출된 견적서를 매출로 작업을 하는 등 전표 내용을 복사해 사용할 수
있다.
견적서를 매출 전표로 복사
l 전표리스트에서 복사할 견적서를 찾아 더블 클릭하거나 전표복사 명령 버튼을 클릭
  한다.
l 전표구분 입력박스클 클릭하여 매출을 선택한다.




l 상품등록 리스트에 빈 곳 아무 곳이나 클릭하면 화면하단의 명령 버튼 모양이 바뀐
  것을 볼 수 있다.




l 수정할 내용등을 고친후 매출작업과 같은 방법으로 처리하면 먼저의 견적 내용과는
  별개로 새로운 매출 전표가 생기게 된다.
