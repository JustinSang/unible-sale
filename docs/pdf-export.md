# 인쇄 양식 PDF 묶음 (2026-10-15)

## 무엇을 하나
- **전표 PDF 묶음**: 전표입력 화면 «최근 발행 전표 내역» 오른쪽 위 **📄 PDF 묶음** → 지금 조회된 전표를 고르고(유형·검색·정렬) **한 PDF**로. 전표마다 새 쪽에서 시작. 견적·발주는 견적서·발주서 양식, 그 외(매출·매입·반입·반출·납품·수주)는 **거래명세표 원본 양식(한 쪽에 위·아래 두 벌, 16줄)**. 매입·반입은 거래처가 공급자.
- **보고서 PDF 저장**: 장부/집계표의 «원본 양식 인쇄 미리보기» 창 → **📄 PDF 저장**. 미리보기는 1,200줄까지만 보이지만 **PDF는 전체 줄**(28,876줄 품목 재고 = 590쪽, 약 15초·3.3MB).
- **전표 인쇄 창의 PDF 저장**: «원본 양식»·«견적의뢰서(원본)»·«기타 원본 양식» 탭이면 벡터 PDF. 팩스 첨부 PDF도 같은 탭에서는 벡터. («거래명세표(A4)»·«80mm 영수증» 탭은 기존 화면 캡처 방식이며, 한 쪽보다 길면 이제 여러 쪽으로 나눈다.)

## 팩스·보관 방식 (2026-10-15 대표님 확인: 매일 «원본 양식(2단)» A4, 위·아래 한 벌은 보내는 것·한 벌은 보관용, 동산화스너는 팩스로 보냄)
- 원본 양식(2단) 한 쪽 = 위 «(공급자 보관용)» + 아래 «(공급받는자 보관용)». **팩스로 보내는 쪽 = 공급받는자 보관용**.
- 전표 인쇄 창 «원본 양식» 탭의 **출력 선택**: 두 벌(인쇄·보관용) / **받는 쪽 한 벌(팩스용)** / 우리 보관용 한 벌 → 미리보기·인쇄·PDF 저장이 그 선택대로. PDF 파일 이름에 «_팩스용»·«_보관용»이 붙는다.
- **팩스 발송**(전표 인쇄 창 → 팩스 발송)은 원본 양식 탭에서 **받는 쪽 한 벌 벡터 PDF**를 첨부한다(보관용 한 벌은 보내지 않음). ⚠ 실제 팩스 전송 API는 시험하지 않았다(실제로 팩스가 나가므로). PDF 생성 경로는 묶음 시험과 같은 코드.
- **PDF 묶음**(전표입력 📄 PDF 묶음)의 «출력 방식»: ①인쇄·보관용(두 벌, 한 파일) ②팩스 원고(받는 쪽 한 벌, 한 파일) ③**팩스 원고(거래처마다 따로 PDF → ZIP 한 파일)** — 거래처별로 팩스를 보낼 때. 실측: 236건 → 거래처 8곳 PDF 8개 ZIP 887KB(≈25초).
- ZIP 안 파일 이름은 한글 UTF-8 — macOS Finder·윈도우 탐색기는 정상, 구형 `unzip` 명령은 한글 이름에서 실패(`ditto -x -k`는 정상).

## 어떻게 만드나
- `lib/pdfExport.ts`: 원본 양식 렌더러(OriginalSlipForm·OriginalFormReport·RptReportPrint)가 «절대 위치 상자(mm)» DOM이라, `[data-pdf-page]` 상자의 인라인 스타일을 읽어 pdf-lib로 글자·선·상자·도장을 그대로 옮긴다. 글꼴은 `public/fonts/NanumGothic-*.ttf`(OFL, macOS 시스템 글꼴 자산에서 분리)를 **부분 집합으로 내장**. 용지는 A4 세로/가로(원본 쪽 높이가 A4보다 짧아도 위에 맞춰 A4로).
- `lib/pdfOffscreen.tsx`: React 요소를 화면 밖에 그려 쪽 상자를 뽑는다 → 줄 수 제한 없는 보고서·여러 전표 묶음을 쪽 묶음(12쪽)씩 처리.
- `lib/pdfJobs.tsx`: `exportReportPdf`·`exportSlipsPdf`. 화면: `components/PdfBundleModal.tsx`, `SlipOriginalForm.tsx`.
- 저장: 지원 브라우저는 저장 위치 선택 창(`showSaveFilePicker`, 클릭 직후 먼저 요청), 아니면 내려받기.
- 전표 유형 표기 정규화 `lib/slipType.ts`: 이관 전표는 `sales`·`return_sales`처럼 소문자가 섞여 있어(매입·반입 판정이 틀어질 수 있음) 표준형으로 맞춘 뒤 쓴다(PrintModal도 같이 적용).

## 다시 시험하는 법 (프린터·저장 창 없이)
1. 받는 서버: `python3 /private/tmp/claude-501/pdfsrv.py`(POST ?name=… 본문을 파일로 저장, 포트 8898, CORS 허용).
2. 브라우저 콘솔: `window.__pdfCapture=(bytes,name)=>fetch('http://127.0.0.1:8898/?name='+encodeURIComponent(name),{method:'POST',body:bytes})` — 이 연결 고리가 있으면 저장 창을 건너뛰고 바이트를 넘긴다.
3. 확인: `pdfinfo`(쪽 수·A4), `pdftotext -layout`(글자·값), `pdftoppm -r 60 -png`(그림으로 육안 확인).
4. ⚠ 시험 스크립트가 «인쇄» 버튼을 누르면 macOS 프린트 창이 떠 화면이 멈춘다 — 모달 닫기는 헤더의 마지막 버튼으로.

## 알려진 한계·추정
- 글꼴은 원본(굴림체) 대신 나눔고딕 — 영숫자 폭이 넓어 좁은 칸은 가로로 눌러 넣는다(글자는 0.8배, 숫자·날짜는 0.5배까지 눌러서 **끝 글자를 자르지 않는다**; 긴 글자는 끝을 자른다).
- 도장은 원본 114px 그림(흰 배경→투명 변환)이라 크게 확대하면 흐리다.
- 원본 인쇄본이 없어 «원본과 한 글자도 다르지 않다»는 보증은 못 한다 — 복원 좌표대로 화면과 PDF가 같다는 것까지.
- «거래명세표(A4)»·«80mm 영수증» 탭의 PDF는 여전히 화면 캡처(비트맵).

## 이전 단정 정정
`html2canvas+jsPDF`(기존 «PDF 저장»)는 비트맵 한 장이라 긴 전표는 잘리고 글자가 흐렸다. 원본 양식 탭은 이제 벡터 PDF.
