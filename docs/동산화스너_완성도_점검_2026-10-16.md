# 동산화스너 완성도 점검 (2026-10-16) — «지금 쓸 수 있나, 기성제품보다 나은가»

기준: 동산화스너(아버지 회사·물려받을 회사)가 **이 컴퓨터에서 지금 실제 업무**를 하고, 기성 ERP(이카운트 등)보다 확실히 나아야 다른 회사에 팔 가능성이 있다. 표기: ✅실측 확인 / 🟡코드만·부분 확인 / ❌못 함·미확인 / ⛔대표님 결정·로그인 필요.

## 2. 측정한 속도 (이 컴퓨터, 로컬)
- 첫 화면에서 **품목 28,876·전표 5,706·거래처 1,095·세금계산서 2,488** 전체 로드·표시: 페이지 시작 후 **약 0.5초 이내**
- 품목 28,876개 검색(전표 입력창): **23~33 ms**(검색어 입력 → 결과 표시)
- API: 거래처 0.15초, 품목 0.29초, 전표 0.42초, 미동 발주내역 19,297줄 0.62초
- 이카운트 같은 기성 서비스의 속도는 **측정하지 못했다**(체험 계정 로그인 필요) → «기성보다 빠르다»는 말은 아직 근거가 없다.

## 3. 기성 ERP와 비교한 강점(근거 있는 것만)
| 강점 | 근거 |
|---|---|
| 동산화스너가 쓰던 오케이세일 화면·양식·단축키·계산 규칙을 그대로 복원(원본 어셈블리·데이터 대조) | 일계표 집계식·어음 상태코드·Balance 규칙 실측, 인쇄 양식 43종 .rpt 해독 |

| 변경 이력(누가·무엇을·전/후, 삭제분 전체 보존) | audit_log 시험 |

| 엑셀 가져오기(품목 단가·새 품목·거래처·초기이월금)·미리보기 후 반영 | 격리 DB 시험 |

| 로컬 데이터라 인터넷 없어도 사무실에서 동작, 데이터가 내 컴퓨터에 있음 | 구조상 |

## 4. 기성보다 부족한 것(숨기지 않는다)
모바일 앱(웹은 폰에서 열림), 은행·카드·국세청 자료 연동, 그룹웨어·전자결재·인사급여·생산, 사용자·권한 관리 화면(역할은 환경변수), 클라우드 다중 사용자 안정성(로컬 한 대). **«월등히 좋다»를 말하려면** ① 초기이월금까지 넣어 장부가 실제와 맞고 ② 로그인·백업이 켜진 채 한 달 실사용 ③ 같은 업무를 이카운트로 해 본 시간 비교가 필요하다.

## 5. 대표님이 정하거나 해 주실 것(동산화스너 «완벽 마무리»에 필요한 것만)
1. **로그인 켜기**: 아이디·비밀번호(직원이 쓰기 전·인터넷 접속 전) — 방법은 `docs/운영_가이드_동산화스너.md` §5
2. **실제 거래처별 잔액표(엑셀)**: 기준일과 함께 주시면 초기이월금 입력
3. **팝빌 콘솔**: 팩스 서비스 가입·연동환경 확인(또는 복합기 팩스로 운영)
4. Supabase를 다시 만들지(장기 운영 DB) 로컬 DB로 당분간 갈지
5. 이카운트 체험 계정(속도·업무 시간 비교용)
